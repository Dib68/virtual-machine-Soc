# Percorso di studio e risorse (cybersecurity)

## Per iniziare (entry level / SOC analyst)
- Piattaforme pratiche: TryHackMe (percorso "SOC Level 1"), Blue Team Labs Online,
  LetsDefend, CyberDefenders.
- Certificazioni citate negli annunci entry: CompTIA Security+, CySA+,
  BTL1 (Blue Team Level 1), eJPT (per il lato offensivo).

## Red team / pentest
- Piattaforme: Hack The Box, PortSwigger Web Security Academy (gratis, per Burp),
  VulnHub.
- Certificazioni: eJPT -> OSCP (la piu' richiesta per i pentester), eWPT.

## Cloud security
- AWS Security Specialty, AZ-500 (Azure), Google Professional Cloud Security.
- Pratica gratuita: flaws.cloud, CloudGoat.

## Bersagli inclusi in questa VM (in locale, sicuri)
- DVWA, OWASP Juice Shop, WebGoat -> avviali con: `soclab targets up`

## Framework e standard da conoscere
- MITRE ATT&CK, NIST CSF, OWASP Top 10, Cyber Kill Chain.

## Consigli per il CV / colloquio
- Documenta progetti pratici (es. "ho configurato Wazuh e creato regole di
  detection", "ho analizzato un pcap con Suricata/Zeek").
- Sapere almeno UN SIEM (Splunk SPL o Wazuh) fa la differenza per i ruoli SOC.
- Scripting (Python/Bash) per automatizzare l'analisi dei log.
