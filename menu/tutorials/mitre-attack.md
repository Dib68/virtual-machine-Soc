# MITRE ATT&CK - il framework da conoscere
## Cos'e'
Una base di conoscenza di tattiche e tecniche degli attaccanti (TTP).
Quasi tutti gli annunci SOC/threat intel la citano.
## Come si usa
- Tattiche = "il perche'" (es. Initial Access, Persistence, Exfiltration).
- Tecniche = "il come" (es. T1566 Phishing, T1059 Command Interpreter).
- Mappa gli alert del SIEM alle tecniche per capire la kill chain.
Sito: https://attack.mitre.org
