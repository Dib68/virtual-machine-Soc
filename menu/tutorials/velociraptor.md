# Velociraptor - DFIR e threat hunting sugli endpoint
## Cos'e'
Piattaforma per raccolta forense e hunting su larga scala, basata su un
linguaggio di query (VQL).
## Uso base
```
velociraptor gui                  # avvia la GUI locale
velociraptor artifacts list       # elenca gli artefatti disponibili
```
Ottimo per incident response e raccolta evidenze da molte macchine.
