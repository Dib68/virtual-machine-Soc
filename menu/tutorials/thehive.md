# TheHive - Security Incident Response Platform (SIRP)
## Cos'e'
Piattaforma per gestire i casi/incidenti di sicurezza in team: crea "case",
"task", "observable" e li analizza con Cortex; si integra con MISP.
## Flusso tipico
Alert (dal SIEM) -> Case in TheHive -> analisi observable con Cortex ->
arricchimento con IOC da MISP -> risposta e chiusura.
