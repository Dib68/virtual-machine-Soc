# OpenWebUI - interfaccia web per l'AI locale
## Cos'e'
Una UI stile ChatGPT, in locale, collegata a Ollama. Comoda per usare
l'assistente "cyberai" dal browser invece che dal terminale.
## In questa VM
```
soclab webui up      # -> http://localhost:3001
```
Al primo accesso crea un account locale e seleziona il modello (cyberai).
